# File handling

Proyecto de entrada/salida en Python: abrir, leer y escribir archivos usando la sentencia `with`.

## Tareas

| Archivo | Descripción |
|---------|-------------|
| `read_file.py` | Lee un archivo de texto UTF-8 y lo imprime en stdout |
| `write_file.py` | Escribe un texto en un archivo UTF-8 y devuelve los caracteres escritos |
| `append_write.py` | Añade un texto al final de un archivo UTF-8 y devuelve los caracteres añadidos |
