# Python - Funciones y modulos

Proyecto del curso UTEC sobre funciones y modulos en Python.

## Archivos

- islower.py: indica si un caracter es minuscula.
- uppercase.py: imprime una cadena en mayusculas.
- print_last_digit.py: imprime y devuelve el ultimo digito.
- pow.py: calcula a elevado a b.
- simple_add.py y test_import.py: uso de __name__.
- add_0.py y add.py: importar una funcion de otro archivo.
