# Python - Estructuras de datos

Proyecto del curso UTEC sobre listas, tuplas, conjuntos y diccionarios.

## Archivos

- print_list_integer.py: imprime los enteros de una lista.
- element_at.py: devuelve un elemento de una lista de forma segura.
- replace_in_list.py: reemplaza un elemento de una lista en una posicion.
- print_matrix_integer.py: imprime una matriz de enteros.
- add_tuple.py: suma dos tuplas de dos enteros.
- common_elements.py: devuelve los elementos comunes de dos conjuntos.
- update_dictionary.py: reemplaza o agrega una clave/valor en un diccionario.
- best_score.py: devuelve la clave con el valor mas alto.
