# Python - Estructuras de datos

Proyecto del curso UTEC sobre listas, tuplas, conjuntos y diccionarios.

## Archivos

- print_list_integer.py: imprime los enteros de una lista.
- element_at.py: devuelve un elemento de una lista de forma segura.
- replace_in_list.py: reemplaza un elemento de una lista en una posicion.
